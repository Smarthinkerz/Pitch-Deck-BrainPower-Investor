# BrainPower AI Pitch Deck — Replication Task

## Reference
The ground-truth spec is the live site at https://pitchdeck.brainpowerinvestor.com/

## Design Spec (from reference)
- **Type**: Single-page 14-slide interactive pitch deck presentation
- **Theme**: Dark futuristic / tech startup
- **Fonts**: Space Grotesk (primary) + Inter (secondary) from Google Fonts
- **Color Palette**:
  - Purple: #6C63FF
  - Cyan: #00D4FF
  - Dark BG: #05080F
  - Panel: #0F1628
  - Border: #1E2A45
  - Muted text: #A0AEC0
  - Green: #00FF88
  - Red: #ff4466
- **Layout**: Fixed 1920x1080 viewport scaled to fit screen, with responsive mobile portrait mode
- **Animations**: Canvas particle backgrounds, staggered reveals, hover glows, animated counters, progress bars
- **Navigation**: Bottom draggable nav bar with dots, arrows, keyboard support, touch/swipe, fullscreen toggle
- **Slides**: 14 total covering Cover, Problem, Solution, Futurescape, Product, Why Different, Market, Use Case, Business Model, Stage, Team, Vision, Investment, Closing

## Implementation Approach
Since this is a replication task, I will build it as a single HTML page (served through the React app) that exactly matches the original structure, styling, animations, and interactivity. The React app will serve as a thin wrapper around the original single-page HTML/CSS/JS implementation to maintain fidelity.
